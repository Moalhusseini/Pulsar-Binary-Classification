# Pulsar Candidate Classification

A small educational binary-classification project using TensorFlow/Keras and a synthetic pulsar-candidate dataset. The notebook compares a baseline neural network, a larger model that demonstrates overfitting, and a regularized model using dropout and early stopping.

## Dataset

The dataset is synthetic (not actual astronomical observations). Download it from [Kaggle – Synthetic Pulsar Candidate Screening](https://www.kaggle.com/datasets/aviral342/synthetic-pulsar-candidate-screening) and place the CSV beside the notebook as `pulsar Data.csv`. Please follow the dataset's license and terms before redistributing the data.

## Run

Open the notebook in Google Colab or Jupyter. Install the packages listed in `requirements.txt`, download the dataset, and run the notebook from top to bottom.

## Tools

- Python
- TensorFlow / Keras
- pandas, NumPy, Matplotlib
- scikit-learn (data preparation and evaluation)

This repository is an educational exercise; the results on synthetic data should not be interpreted as validation on real pulsar observations.
